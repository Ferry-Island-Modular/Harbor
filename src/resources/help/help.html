Harbor

Harbor turns ordinary audio into wavetable banks for Eurorack hardware (Ferry Island Modular's Four Seas) and other wavetable hosts such as Synthesis Technology's Waveedit.

Every bank is an 8 × 8 × 8 grid: 8 output files (the Z axis), each holding 64 single-cycle waveforms arranged as an 8 × 8 X/Y plane. On the hardware you sweep those three axes to move through the sounds.

Getting started

  1. Pick a mode from the launcher screen.
  2. Drop a .wav file onto the drop area, or click it to browse.
  3. Choose how each axis should behave (see below) — the defaults are a sensible starting point.
  4. Click Generate wavetable bank.
  5. Audition it with the preview, then Export wavetable bank to a folder of your choosing.

Three modes

Use any .wav file
Drop in a single ordinary recording — a voice, a field recording, a synth line, anything. Harbor analyses it and builds the whole grid from that one source. This is the mode with the most controls, and the one to start with.
Use a Serum .wav file
Drop in a Serum-format wavetable (2048 samples per frame, any number of frames). Harbor resamples the frame timeline onto the 8 Z pages. Serum exports are usually 32-bit float, but 16-bit and 24-bit files work too, as long as the total sample count is a multiple of 2048.
Use three .wav files
Drop in three recordings, one per slot: Source A is where the X axis starts, Source B is where X ends, and Source C is the Y destination. Each cell blends the three spectra according to its position in the grid.

Any-WAV controls

Source treatment

Decides which part of your recording Harbor draws on, and what the X axis sweeps through.

Focused (default)
Scans spectrally distinct frames from a content-rich region. Harbor finds the most interesting stretch of the file and picks frames that differ from one another, so the X axis moves through genuinely different timbres. Best for most material.
Legacy stretch
Scans the full source while stretching its spectrum. Uses the whole file end to end rather than choosing a region. Useful when the entire recording matters, or to reproduce results from earlier versions of the tool.

Y axis

Reshapes the spectrum as you move up the Y axis.

Tilt (default)
Shifts energy between low and high frequencies. One end is dark and bass-heavy, the other bright and treble-forward.
Formant
Stretches or compresses the spectral envelope without changing the pitch. Produces vowel-like and resonant-body shifts.
Stretch
Widens the spacing between harmonics. Low values keep natural whole-number ratios; high values push them apart into inharmonic, metallic, bell-like territory.
Smear
Blurs the spectrum by averaging neighbouring frequencies. Sharp at low values, washed-out and pad-like at high values.

Z axis

Changes the texture across the 8 output pages.

Random (default)
Randomises the phase of each frequency. Brightness stays the same but the waveform shape changes, giving each page its own character.
Disperse
Smears energy across the cycle by frequency. Grows progressively more diffuse and chorus-like as Z increases.
Crush
Quantises the waveform to fewer amplitude levels for digital distortion and aliasing. Deliberately extreme at the top end — use your module's attenuators.

Serum controls

Serum mode offers a different set of transforms from Any-WAV mode, because the source is already a wavetable.

Y axis — spectral colour
Formant (default) shifts the spectral envelope; Smear blurs the spectrum; Stretch widens harmonic spacing.
Z axis — texture
Odd / even (default) rebalances odd against even harmonics, moving between hollow and full; Phase motion shifts phase progressively across pages; Crush quantises amplitude for digital grit.

Three-WAV controls

Z axis — texture
Phase motion (default), Odd / even, Crush, and Harmonic comb, which notches out regularly spaced harmonics for a hollow, phasey character. The X and Y axes are set by the three source files rather than by a mode.

Preview

Once generation finishes, the preview panel appears with X, Y, Z, Pitch and Volume sliders. Click Play steady tone to hear the bank and drag the sliders to move through the grid; the button becomes Stop while it plays. The preview always sounds the 2048-sample version, whichever export target you have selected.

Output directory

Banks are saved to ~/Documents/Harbor/ by default. Change it with File > Choose output directory…. Each generated bank is eight numbered .wav files, one per Z page.

Target hardware

Choose under Export > Target hardware:

  • Four Seas (2048 samples per cycle) — the default, for Ferry Island Modular's Four Seas.
  • Waveedit (256 samples per cycle) — for Synthesis Technology's Waveedit and other 256-sample hosts.

Set this before exporting. It changes the files written to disk, not the preview.

Reporting bugs

Harbor is in beta, so please do report anything odd — including things that look wrong rather than crash.

Issues go to github.com/Ferry-Island-Modular/Harbor/issues. Helpful to include: your Harbor version from Help > About Harbor, your operating system, which mode and axis options you used, and what you expected to happen instead.

Harbor

Harbor generates wavetable banks for Eurorack hardware (Ferry Island Modular's Four Seas) and other wavetable synth hosts (e.g. Waveedit / Synthesis Technology).

Three modes

Use any .wav file
Drop in a single audio file. Harbor analyzes it and creates an 8 page × 64 cell wavetable bank by spectrally morphing the source across the X, Y, and Z axes. The Y and Z morph mode selectors control how the spectrum is transformed (see Morph modes below).
Use a Serum .wav file
Drop in a Serum-format wavetable (2048 samples per frame, any number of frames). Harbor resamples the frame timeline to 8 pages and applies the same Y/Z morph modes as Any-WAV mode. Serum exports are typically 32-bit float, but Harbor also accepts 16-bit and 24-bit files as long as the total sample count is a multiple of 2048.
Use three .wav files
Drop in three audio files, one per axis. Each cell in the 8×8×8 grid blends the three files' spectra weighted by the cell's position. No morph modes — all the variety comes from the three source files you pick.

Morph modes

The Y axis and Z axis morph modes (available in Any-WAV and Serum modes) control how the source spectrum is transformed as you move along each axis. Each mode is applied independently.

Y axis modes

Spectral tilt (default)
Tilts the magnitude spectrum, shifting energy between low and high frequencies. At one end the timbre is dark and bass-heavy; at the other it's bright and treble-forward.
Formant scale
Stretches or compresses the spectral envelope (the formant structure) without changing the fundamental pitch. Creates vowel-like or resonant-body shifts.
Harmonic stretch
Stretches the spacing between harmonics. Low values keep harmonics at their natural integer ratios (1x, 2x, 3x…); high values push them apart into inharmonic, metallic, bell-like territory.
Spectral smear
Blurs the magnitude spectrum by averaging neighboring bins. Low values leave the spectrum sharp; high values diffuse it into a washed-out, pad-like timbre.

Z axis modes

Random phase (default)
Randomizes the phase of each spectral bin. Preserves the magnitude spectrum (same perceived brightness) but changes the waveform shape, producing a different texture on each Z page.
Phase disperse
Applies a frequency-dependent phase shift that spreads energy across the cycle. Creates a progressively more diffuse, chorus-like character as the Z value increases.
Bit crush
Quantizes the waveform amplitude to fewer levels, introducing digital distortion and aliasing artifacts. Extreme at high values — Eurorack users have attenuators.

Output directory

Use File > Choose output directory… to pick where Harbor saves the generated banks. By default they go to ~/Documents/Harbor/, organized into per-mode subdirectories.

Target hardware

Use Export > Target hardware to choose between:

  • Four Seas (2048 samples per cycle) — the default. Compatible with Ferry Island Modular's Four Seas oscillator.
  • Waveedit (256 samples per cycle) — compatible with Synthesis Technology's Waveedit and other 256-sample wavetable hosts.

The preview always plays the 2048-sample version regardless of which target you've selected.

Preview

After Generate finishes, the preview panel appears with X, Y, Z, Pitch, and Volume sliders. Click Play steady tone to audition the bank. Drag the sliders to scan through the wavetable grid.
